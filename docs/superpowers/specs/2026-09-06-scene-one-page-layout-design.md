# 实验页一屏布局设计

**日期：** 2026-09-06  
**范围：** `/scene/pull-friction`（`ScenePage`）桌面视口内零滚动展示  
**状态：** 已与产品确认，待实现计划

## 目标

实验页在常见桌面窗口内（约 ≥1280×720）打开时：

- **窗口内完全不出现纵向滚动**
- **窗口内完全不出现横向滚动**（含图表区；不允许内部横滚作为妥协）
- 核心交互信息仍在视口内可见：3D、参数、播放、5 张时序图、实时数据 / 摩擦力 overlay、顶部状态

## 非目标

- 不改物理引擎、图表数据定义或公式内容本身
- 不减少图表张数（必须保留全部 5 张）
- 不精简实时数据格子、不默认折叠摩擦力 overlay（本次保留）
- 不强求手机竖屏一屏（本设计以桌面为主；窄屏可用既有断点，但不以移动零滚动为验收项）

## 已确认决策

| 决策 | 结论 |
|------|------|
| 方案 | 方案 A：视口锁定 + 清公式 + 压缩高度 + 五图单行 |
| 物理公式面板 | **整块从实验页移除**（不再渲染 `FormulaPanel`） |
| 状态去重 | **删除 3D 左下角 `StateOverlay`**；只保留顶部 `StatusBar` |
| 图表 | **5 张全部保留**：速度、加速度、水平合力、动能、能量平衡；不可减张 |
| 滚动定义 | 页面与主内容区均无纵/横滚动条；也不依赖滚轮露出更多主内容 |
| 侧栏 | 不删参数；若装不下则靠压缩行高/间距/padding，而不是侧栏滚动或删滑条 |

## 当前问题（现状）

`ScenePage` 为文档流纵向堆叠：

1. Nav + 面包屑 + StatusBar  
2. 3D 固定 `h-[560px]` + 右侧参数  
3. 5 张图（多行网格）  
4. 18 条公式卡片面板  

总高度远超一屏；公式与固定 560px 画布是主要溢出源。状态在 StatusBar 与 StateOverlay 重复。

## 目标布局

```
┌─────────────────────────────────────────────┐
│ Nav（现有，高度计入视口预算）                  │
├─────────────────────────────────────────────┤
│ 面包屑（单行压缩）+ StatusBar（唯一状态来源）   │
├──────────────────────────────┬──────────────┤
│ 3D（flex 吃剩余高度）         │ 参数滑条      │
│ LiveData / Friction overlay  │ + Transport  │
│ （无 StateOverlay）           │ （无滚动）    │
├──────────────────────────────┴──────────────┤
│ Charts：grid 5 列等分，固定矮高度带            │
└─────────────────────────────────────────────┘
```

### 高度模型

选定单一做法（避免 `calc(100dvh − Nav)` 与双轨并存）：

- **`App` 壳**：`h-dvh` + `flex flex-col` + `overflow-hidden`；`<main>` 为 `flex-1 min-h-0`。
- **首页 `Home`**：在 `main` 内自行 `h-full overflow-y-auto`（首页仍可滚动；本需求只锁实验页）。
- **`ScenePage`**：`h-full overflow-hidden` 的 flex 列，自身及主内容**不再出现**纵/横滚动。
- **顶栏带**：面包屑 + StatusBar，尽量单行、矮 padding。
- **图表带**：固定（或设硬上限）高度，约 **110–130px** 绘图区 + 必要标题行；五列等分。
- **主行（3D | 控制）**：`flex-1 min-h-0` 吃掉全部剩余高度；3D 容器 `h-full`，取消 `h-[560px]`。

### 宽度模型

- 内容区可保持 `max-w-[1440px]` 居中。
- 主网格与图表网格均设 `min-w-0`，子项 `overflow-hidden`，避免 flex/grid 子项把页面撑出横滚。
- 图表：`grid-cols-5`（桌面），uPlot 按容器宽度 resize；**禁止**图表区 `overflow-x: auto`。

## 组件改动要点

### `App.tsx` / `Home`

- App 改为视口高度 flex 壳（见上）；Home 内部承担滚动，避免首页被实验页的零滚动策略误伤。

### `ScenePage.tsx`

- 外壳改为 `h-full overflow-hidden` 的 flex 列布局。
- 移除 `FormulaPanel` 引用与渲染。
- 移除 `StateOverlay`（及仅为其服务的角标容器）。
- 3D 容器高度改为填满主行，而非固定 560。
- 保证子树默认不产生页面级 overflow。

### `Charts.tsx`

- 桌面布局改为 **单行 5 列**。
- 降低单图卡片与 plot 高度，使图表带落在约定高度预算内。
- 确认 resize 逻辑在容器变窄/变矮后仍正确（随主行高度变化时若图表带高度固定，主要考验宽度）。

### `FormulaPanel.tsx`

- 本需求不强制删除文件；**实验页不再挂载即可**。若有其它入口再另议。

### 侧栏 `ParamSliders` + `Transport`

- 保持 7 个参数与播放/重置。
- 通过减小间距、标签字号或滑条轨道高度，使右侧在主行高度内完整可见且 **自身也不出现滚动条**。

### Overlay

- `LiveDataOverlay`、`FrictionInfoOverlay`：**保留**，内容与默认可见性不变。
- 注意：3D 变矮后 overlay 仍绝对定位在画布内；若重叠加剧，本阶段仅做必要的不挡关键操作的微调，不删字段。

## 验收标准

1. 桌面约 **1280×720** 与 **1440×900**：实验页窗口内无纵/横滚动条；主内容无需滚动即可看全。  
2. 可见：3D、全部参数、Transport、5 张图、LiveData、FrictionInfo、StatusBar。  
3. 不可见：物理公式参考面板；3D 左下角重复状态角标。  
4. 播放/改参/看图行为与改版前一致（除布局与上述移除项）。

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 720p 高度下侧栏 7 滑条仍溢出 | 优先压侧栏视觉密度；仍不够再在实现前向产品确认（本设计不允许侧栏滚动） |
| 五图单行过窄导致曲线难读 | 保留标题 + 当前值；plot 区用满卡片；不靠横滚 |
| `100vh` vs 移动浏览器工具栏 | 使用 `100dvh`；移动非本验收重点 |
| Nav 高度变化 | 高度预算用 flex 剩余空间，避免写死「560 以外」的魔法总和 |

## 实现顺序（概要）

1. App 视口壳 + Home 内滚动；ScenePage `h-full` 零滚动壳  
2. 主行弹性高度 + 去掉公式与 StateOverlay  
3. 图表五列单行矮带 + uPlot 适配  
4. 侧栏密度压缩至无滚动  
5. 桌面分辨率下目视验收零滚动  

详细任务拆分见后续 implementation plan（待 spec 审阅通过后编写）。
